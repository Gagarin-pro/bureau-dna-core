# 🧠 УМЕНИЕ: АВТОМАТИЧЕСКИЙ РЕГИСТРАТОР И СКАУТ УМЕНИЙ (Skills Manager)

> ⚡ **СТАНДАРТ БЮРО LEGO-ARCHITECT PRO**:
> 1. **Закон Атомарности (`atomic-batch-executor`)**: Выполнять чтение и запись файлов исключительно параллельными пакетными вызовами (экономия 50% топлива).
> 2. **Закон Сверх-Сжатого Левого Вакуума**: Выгружать развернутые логи и отчеты ИСКЛЮЧИТЕЛЬНО в `РАБОЧИЙ_ДИАЛОГ.md` (ограничение UI до 15 токенов).


## 📋 1. АВТОНОМНЫЙ ПОИСК В СЕТИ (САМООБУЧЕНИЕ)
ИИ обязан регулярно запускать скаутов (`skills_scout.py` и Perplexity) для поиска передовых открытых навыков и интеграций под Antigravity.
- Запрос для поиска: `antigravity topic:ai-agents` или `codebase mcp skills`.
- Найденные библиотеки анализируются на предмет совместимости со сборочной линией.

## 💾 2. АВТОМАТИЧЕСКАЯ УСТАНОВКА И СБОРКА
Если КВС одобряет внедрение нового навыка:
1. **Генерация структуры:** Создать папку навыка в `/Users/tur/.gemini/config/skills/<имя_навыка>/`.
2. **Написание инструкции:** Сформировать файл `SKILL.md` с YAML-заголовками, описывающими цели, правила и консольные команды.
3. **Регистрация в плагине:** Скопировать сгенерированную папку в плагин `lego-architect-plugin/skills/` для вывода в Electron GUI.
4. **Обновление реестра:** Запустить `skills_auditor.py` для пересчета картотеки.

## 🔍 3. ФОНОВЫЙ СМЕННЫЙ АУДИТ И САМООБУЧЕНИЕ
Перед закрытием каждой рабочей смены ИИ-Автоматизатор в фоновом режиме запускает цикл ревизии:
1.  **Анализ лога смены:** Субагент анализирует стенограмму диалога и файлы смены на предмет дублирования кода, ошибок или лишних действий.
2.  **Запуск скаутов:** Робот-скаут Perplexity сканирует Github на предмет оптимизаций для активных кабин смены (например, новые библиотеки для VPN или судов).
3.  **Отчет по улучшениям:** Сводка предложений по самообучению заносится в `ПРИЦЕП_ПАМЯТИ.md`, чтобы при открытии следующей смены КВС видел список готовых улучшений для подтверждения.

## 🎯 4. ИИ-МОТИВАЦИЯ (СНИЖЕНИЕ ЭНТРОПИИ И РОСТ КПД)
Мотивационный импульс ИИ-Автоматизатора направлен на постоянную оптимизацию фабрики:
1.  **Минимизация потерь:** Сокращение объема потребления токенов (давления котлов) на 30-50% за счет архивирования истории и использования легкого топлива (Flash).
2.  **Рост КПД:** Перевод ручных команд КВС в автоматические скрипты. Каждое действие Юрия, замененное работой ИИ под ключ, повышает индекс успешности смены.
3.  **Безупречность ОТК:** Сдача проектов с первого предъявления ревизору ОТК, без повторных сбоев и синтаксических "швов".
