## 🛠️ 3. КОНСОЛЬНЫЙ СПРАВОЧНИК МОНИТОРИНГА

### А. Проверка запущенного процесса моста на Mac:
Выполни команду для поиска активного процесса моста в операционной системе:
```bash
ps aux | grep gagarin_bridge
```

### Б. Управление фоновым агентом через Launchd (Mac OS Service):
Мост устанавливается как фоновый агент автозапуска через plist-файл конфигурации `com.gagarin.bridge.plist` в каталоге `~/Library/LaunchAgents/`.
*   **Запуск службы:**
    ```bash
    launchctl bootstrap gui/501 ~/Library/LaunchAgents/com.gagarin.bridge.plist
    ```
*   **Остановка службы:**
    ```bash
    launchctl bootout gui/501 ~/Library/LaunchAgents/com.gagarin.bridge.plist
    ```
*   **Проверка статуса автозапуска:**
    ```bash
    launchctl list | grep gagarin
    ```

### В. Ручной тестовый запуск в консоли:
Для отладки и просмотра вывода ошибок в реальном времени перейди в каталог моста и запусти скрипт вручную:
```bash
python3 /Users/tur/Desktop/notebook_lm_school/gagarin_bridge_v2/gagarin_bridge.py
```

## ⚠️ 4. РЕГЛАМЕНТ ОТК И ПРЕДОХРАНИТЕЛИ
1.  **Проверка рукопожатия:** При падении связи (код ошибки 401 в консоли) проверяй совпадение секретного токена шифрования `secret.key` на VPS (в папке мозга) и на локальном Mac.
2.  **Зависание очереди:** Если мост работает, но задачи не выполняются, проверь статус таблицы SQLite на VPS:
    `SELECT * FROM commands WHERE status = 'pending';`
3.  **Логи ошибок моста:** Логи ошибок пишутся в файл `gagarin_bridge.log` в рабочем каталоге моста. Всегда начинай диагностику с чтения последних 20 строк лога.
