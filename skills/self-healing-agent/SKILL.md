> ⚡ **СТАНДАРТ БЮРО LEGO-ARCHITECT PRO**:
> 1. **Закон Атомарности (`atomic-batch-executor`)**: Выполнять чтение и запись файлов исключительно параллельными пакетными вызовами (экономия 50% топлива).

## 📌 Описание
Навык авто-ремонта кода при падении сборки или тестов:
1. **Log Interception:** Считывает un-truncated лог ошибки при сбое команды.
2. **Root Cause Analysis:** Определяет первичное нарушение контракта ( signature / null check / import ).
3. **Recursive Patch:** Накладывает точечный фикс и повторно запускает компиляцию до получения зеленого статуса.
