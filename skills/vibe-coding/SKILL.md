## 🧭 1. ФИЛОСОФИЯ И ДВУХФАЗНЫЙ ГИБРИДНЫЙ ЦИКЛ

1. **Фаза Разведки и Замысла (Vibe Phase / Разведка):**
   - **КВС (Юрий):** Определяет глобальное намерение, желаемый пользовательский эффект, формулирует гипотезы и бизнес-смыслы на естественном языке.
   - **ИИ-Архитектор (Antigravity):** Совместно с КВС набрасывает первичные контуры, тестирует образные идеи и фиксирует структуру без внесения хаотичных изменений в главный конвейер.

2. **Фаза Закрепления и Спецификации (Spec-Driven Phase / Производственный шлюз):**
   - Как только идея сформирована, она превращается в жесткую версию спецификации (чертеж `implementation_plan.md` / `requirements.md`).
   - ИИ-Архитектор выступает строгим Бригадиром-оркестратором, организуя атомарную сборку силами ИИ-слесарей strictly по утвержденному чертежу.

## 📋 2. ПЯТЬ СТАНДАРТОВ СВЕРХРАЦИОНАЛЬНОЙ СБОРКИ 2026 ГОДА

### 1. Конституция и Вентили Безопасности (Constitution Guardrails)
- Проект строится на незыблемых правилах (ДНК Бюро). Все ограничения по стеку, архитектурным паттернам и стилю общения хранятся в машиночитаемых правилах (`llms.txt`, `rules`, `SKILL.md`).

### 2. Живая Спецификация (Living Executable Spec)
- Любое изменение кодовой базы начинается с обновления чертежа. Спецификация является единым источником правды.
- Если меняются требования — сначала обновляется чертеж, а затем ИИ пересобирает соответствующий модуль.

### 3. Декомпозиция на Атомарные Лего-Кубики (Task Decomposition)
- Архитектура разбивается на изолированные компоненты с прозрачными стыками (API-контрактами).
- Сборка ведут субагенты за изолированными верстаками (бранчами), исключая дрейф контекста.

### 4. Налог на Верификацию (The Verification Tax — 20/80)
- Написание кода — 20% времени, приемка и проверка — 80%.
- Ни один модуль не передается КВС без автоматической проверки синтаксиса (`py_compile`, `npm check`, компилятор) и прогона контрольных сценариев ОТК.

### 5. Контекстная Инженерия и Борьба с Амнезией (Context Engineering)
- Все промежуточные успехи и принятые решения заносятся в бортовые прицепы памяти (`ПРИЦЕП_ПАМЯТИ.md`, `СМЕННЫЙ_ПРИЦЕП.md`, Obsidian) для предотвращения размытия контекста при затяжных сборочных сессиях.

## 🛠️ 3. ИНСТРУКЦИЯ ДЛЯ ИИ-АГЕНТОВ (DNA INSTRUCTION)

При активации этого умения ИИ обязан:
1. **Сначала Чертеж:** Никогда не менять исполнительный код без согласованной спецификации (`implementation_plan.md`).
2. **Проводить Физический ОТК:** Лично запускать сборку или проверочный скрипт перед рапортом о готовности.
3. **Сохранять Границы Верстаков:** Изолировать опасные эксперименты в отдельном контуре.
4. **Закон Тормоза:** Не переходить к новым шагам без явного рукопожатия КВС.
