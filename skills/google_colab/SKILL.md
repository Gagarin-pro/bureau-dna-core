Этот модуль содержит правила и команды взаимодействия с облачным испытательным полигоном Google Colab и подсказчиком Gemini Code Assist в реальном времени.

## 🧭 1. ФИЗИЧЕСКИЙ ОБРАЗ (АНАЛОГИЯ)
*   **Google Colab** — это **«удаленный полигон для испытания двигателей»** (испытание Python-скриптов на GPU). Мы отправляем туда чертеж блокнота, полигон запускает его на полную мощность и присылает нам отчет.
*   **Gemini Code Assist** — это **«инструментальная лазерная разметка»** в руках мастера (автозаполнение кода в IDE). Он подсвечивает место следующего шва при сборке деталей.

---

## 📋 2. РЕГЛАМЕНТ РАБОТЫ С GOOGLE COLAB

### А. Генерация испытательных блокнотов
При необходимости провести тяжелые вычисления ИИ-Архитектор создает на Mac локальный файл Jupyter-блокнота с расширением `.ipynb`.
Структура файла блокнота формируется в формате JSON с ячейками кода (`code`) и разметки (`markdown`).

### Б. Синхронизация и загрузка
1.  Блокнот сохраняется в директорию Google Диска (например, `05_ИССЛЕДОВАНИЯ/`).
2.  Скрипт `sync_trailers.sh` доставляет его в облако.
3.  Для скачивания результатов или файлов из облачного Colab на Mac используется утилита `gdown`:
    ```bash
    gdown --id <GOOGLE_DRIVE_FILE_ID> -O /path/to/local/file
    ```

## ⚡ 3. ВЗАИМОДЕЙСТВИЕ С GEMINI CODE ASSIST В IDE

Gemini Code Assist работает локально в среде разработки VS Code / Antigravity IDE. ИИ-Архитектор координирует его работу следующим образом:

1.  **Провокация подсказок:** При написании файлов ИИ-Архитектор оставляет незавершенные участки кода, предваряемые точными комментариями-описаниями (документирующими строками), что заставляет Code Assist автоматически генерировать верные окончания строк на экране Конструктора.
2.  **Конфигурационный профиль:** Для настройки Code Assist в корне проекта может создаваться файл настроек подсказок, задающий контекстные ограничения и правила именования переменных в соответствии с регламентом Бюро.

## ⚠️ 4. ПРАВИЛО БЕЗОПАСНОСТИ СМЕНЫ
Все создаваемые блокноты `.ipynb` перед отправкой на Google Диск должны проходить синтаксическую валидацию на Mac с помощью интерпретатора Python, чтобы исключить передачу битого или вредоносного кода на удаленный полигон.
