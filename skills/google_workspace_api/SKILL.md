Этот модуль содержит правила сопряжения ИИ-агентов с REST API сервисов Google Workspace, схемы авторизации и методы работы с таблицами, файлами и почтовыми конвертами.

## 🧭 1. ФИЗИЧЕСКИЙ ОБРАЗ (АНАЛОГИЯ)
Google Workspace APIs — это **«Трубопроводная сеть с конвертами»**. По этим трубам агенты посылают друг другу и Архитектору письма (Gmail), ведомости в ящиках (Sheets), папки с чертежами (Drive) и расписания смен (Calendar). Бригадир следит за герметичностью труб и за тем, чтобы на почтовых конвертах стояли правильные печати (токены OAuth).

---

## 🔑 2. СХЕМЫ АВТОРИЗАЦИИ (ПЕЧАТИ ДОСТУПА)
Для подключения к API используются два типа пропусков:
1.  **Сервисный аккаунт (Service Account JSON):** Используется для фоновой автоматизации (n8n, локальный мост). Ключ доступа хранится в файле `service_account.json` на сервере.
2.  **Пользовательский OAuth 2.0 (Client ID/Secret):** Используется, когда агент действует от имени Архитектора (Юрия). Требует первичного подтверждения в браузере (через порт 9222) и кэширования refresh-токена в `token.json` для предотвращения повторной авторизации.

## 🛠️ 3. СПРАВОЧНИК ОПЕРАЦИЙ

### Чтение и запись ведомостей (Google Sheets API):
```python
# Пример записи в ведомость
from googleapiclient.discovery import build
service = build('sheets', 'v4', credentials=creds)
sheet = service.spreadsheets()
body = {'values': [['ПОБЕДА №84', 'Успешный тест-драйв API']]}
sheet.values().append(
    spreadsheetId='1xABC...', range='Лист1!A1',
    valueInputOption='USER_ENTERED', body=body
).execute()
```

### Сканирование склада чертежей (Google Drive API):
```python
# Поиск файлов, измененных за последние 10 минут
import datetime
time_threshold = (datetime.datetime.utcnow() - datetime.timedelta(minutes=10)).isoformat() + 'Z'
query = f"modifiedTime > '{time_threshold}' and mimeType = 'text/plain'"
results = drive_service.files().list(q=query, fields="files(id, name, modifiedTime)").execute()
```

## 🚥 4. РЕГУЛИРОВКА ДАВЛЕНИЯ И ЛИМИТЫ (RATE LIMITS)
1.  **Защита от гидроудара (Ошибка 429):** При массовом опросе файлов Google Drive API может заблокировать доступ. Бригадир обязан закладывать паузу (пауза 2–3 секунды) между запросами или использовать экспоненциальную задержку (Exponential Backoff).
2.  **Сжатие пакетов:** При передаче длинных списков задач не отправляй каждую строчку отдельным конвертом (API-вызовом). Упаковывай их в единый пакет (Batch Request) для экономии лимитов соединений.
