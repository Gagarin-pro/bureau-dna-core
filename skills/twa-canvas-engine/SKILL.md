Умение описывает стандарты отрисовки сложных структур данных (бинарных матриц) на HTML5 Canvas внутри Telegram Mini Apps (TWA).

---

## 📐 1. РЕНДЕРИНГ БИНАРНОЙ МАТРИЦЫ (BFS CANVAS DRAWING)

При отрисовке дерева участников:
1.  **Координатная сетка:** Расчет позиций нод по уровням глубины:
    *   Уровень \(Y\) равен `level * vertical_gap`.
    *   Смещение по оси \(X\) рассчитывается динамически на основе индекса ноды в бинарной строке, чтобы избежать пересечения ветвей:
        \[X = parent\_x \pm \frac{horizontal\_gap}{2^{level}}\]
2.  **Оптимизация производительности:**
    *   Использовать `requestAnimationFrame` для сглаживания жестов перемещения.
    *   Применять `OffscreenCanvas` для кэширования статических элементов (фоны нод, линии связей).
    *   Рендерить только видимую область экрана (Culling / Отсечение невидимого).

## 📱 2. ЖЕСТЫ И ТАЧ-СОБЫТИЯ (ZOOM & PAN)

Для мобильных устройств Telegram Mini App:
1.  **Перемещение (Pan):** Отслеживание `touchstart` и `touchmove`. Расчет дельты координат:
    `offsetX += currentX - startX`, `offsetY += currentY - startY`.
2.  **Масштабирование (Pinch to Zoom):**
    *   Измерение расстояния между двумя пальцами через `Math.hypot(e.touches[0].clientX - e.touches[1].clientX, e.touches[0].clientY - e.touches[1].clientY)`.
    *   Изменение масштаба `scale` относительно центральной точки жеста.
3.  **Клик по ноде:** Сравнение координат тапа с массивом bounding-box отрисованных нод с учетом текущего сдвига и масштаба.

---

## 📡 3. ИНТЕГРАЦИЯ С TELEGRAM WEB APPS SDK

1.  **Viewport & Theme Colors:** Считывание цветов темы через `window.Telegram.WebApp.themeParams` для автоматической адаптации темы Canvas (поддержка темных/светлых тонов Сбербанка и Telegram).
2.  **Haptic Feedback:** Использование `window.Telegram.WebApp.HapticFeedback.impactOccurred('light')` при нажатии на ноды для тактильного отклика на смартфонах.
3.  **Параметры запуска:** Использование `window.Telegram.WebApp.initDataUnsafe.start_param` для авто-фокуса на конкретном ID партнера при переходе по глубоким ссылкам (deep linking).
