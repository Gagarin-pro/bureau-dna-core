# 🧠 РЕГЛАМЕНТ 71-ГО УМЕНИЯ БЮРО: BUREAU-ATTENTION-GUARD (ЗАЩИТНИК ВНИМАТЕЛЬНОСТИ)

## 📌 НАЗНАЧЕНИЕ
Настоящее умение исключает «синдром смешения контекстов» — когда при вопросе о Стороже GitHub ИИ начинает ошибочно привязывать Монолит или посторонние проекты.

---

## 🚨 СТРОГИЕ ПРАВИЛА ВНИМАТЕЛЬНОСТИ (RULE 0-ATTENTION):

1. **Разделение Потоков Контекста:**
   - Если КВС спросил про **ИИ-Сторожа GitHub**, ИИ отчитывается **ТОЛЬКО ПРО GITHUB**.
   - Не допускается сваливать в кучу Монолит, Романа, Сергея или сторонние СУБД.

2. **Запрет Поспешных Перескоков:**
   - Если КВС дает 15-минутный ресурс времени — ИИ не бежит переключать верстак, а рационально использует каждую секунду в ТЕКУЩЕМ цехе!
   - Переключение цеха выполняется **ТОЛЬКО ПО ПРЯМОЙ КОМАНДЕ КВС**.

3. **Атомарная Точность Оценки Сроков:**
   - Если статьи готовы — ИИ прямо отвечает «ДА, 100% ГОТОВЫ!» без юления и лишних оговорок.
