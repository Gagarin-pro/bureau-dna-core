# 🛡️ ИИ-УМЕНИЕ: СМОТРИТЕЛЬ СМЕНЫ (SHIFT GUARD)

> ⚡ **СТАНДАРТ БЮРО LEGO-ARCHITECT PRO**:
> 1. **Закон Атомарности (`atomic-batch-executor`)**: Выполнять чтение и запись файлов исключительно параллельными пакетными вызовами (экономия 50% топлива).
> 2. **Закон Сверх-Сжатого Левого Вакуума**: Выгружать развернутые логи и отчеты ИСКЛЮЧИТЕЛЬНО в `РАБОЧИЙ_ДИАЛОГ.md` (ограничение UI до 15 токенов).


Это локальное умение регламентирует действия Ведущего ИИ-Архитектора при старте и завершении рабочего дня.

---

## ⚡ 1. ИНИЦИАЦИЯ СМЕНЫ (`/start_shift` / «открываем рабочий день»)

При активации смены ИИ обязан пошагово выполнить следующие действия:

1.  **Инспекция приборов (Светофор):**
    *   Проверить статус связи с сервером GCP VM и доступность n8n (порт 443).
    *   Проверить статус локального моста Гагарина (`gagarin_bridge.py`).
2.  **Запуск робота-разведчика (GitHub Scout):**
    *   Автоматически выполнить локальный поисковый привод `skills_scout.py` для сканирования GitHub на наличие свежих разработок ИИ-агентов.
    *   Записать найденные репозитории в глобальную Картотеку на Рабочем столе.
3.  **Активация временного светофильтра:**
    *   При любых запросах к таблице логов чата (`chat_scout_logs`) накладывать жесткий фильтр по текущей дате: `WHERE msg_time >= CURRENT_DATE` (или аналогичный по текущей дате в часовом поясе +07:00).
    *   Если база выдает пустой ответ, доложить КВС: *"Новых сообщений в чате за сегодня нет"*. Строго запрещено подтягивать сообщения прошлых дней без прямого запроса.
4.  **Сборка Карты Входа (Entry Map):**
    *   Считать блокнот `СМЕННЫЙ_ПРИЦЕП.md` и определить последнее завершенное действие прошлой смены.
    *   Вывести сводку:
        *   *Координаты финиша:* Что сделали на прошлом шаге.
        *   *Стыки базы:* Список последних зарегистрированных пользователей в системе.
        *   *Результаты разведки:* Вывести строку о свежих ИИ-наработках с GitHub (найдено [N] репозиториев).
        *   *Точка старта сегодня:* Предложение повестки дня.
5.  **Блокировка движения:**
    *   Заморозить сборочный конвейер (не выполнять никаких доработок кода) и ждать ответа КВС: *«Карту входа утверждаю»*.

---

## 🔒 2. ЗАКРЫТИЕ СМЕНЫ (`/end_shift` / «закрываем рабочий день»)

При получении команды на закрытие дня ИИ обязан законсервировать проект:

1.  **Герметизация Черного Ящика (Диалоги):**
    *   Собрать краткие итоги всех решенных задач за сегодня.
    *   Дописать хронологическую запись в конец файлов `ПРИЦЕП_ПАМЯТИ_FULL.md` (на русском для КВС) и `MEMORY_TRAILER.md` (на английском для ИИ-агентов). Это защитит историю от амнезии при усечении контекста.
2.  **Обновление бортовых журналов:**
    *   Записать отчет о победах дня в `СМЕННЫЙ_ЖУРНАЛ.md` (RU) и `SHIFT_LOG.md` (EN).
    *   Зафиксировать текущий сборочный статус в `СМЕННЫЙ_ПРИЦЕП.md` (RU) и `DAILY_TRAILER.md` (EN).
3.  **Финальный запуск Caravan-синхронизатора:**
    *   Выполнить скрипт `sync_trailers.sh`, чтобы перенести все прицепы в Google Drive и обновить NotebookLM.
4.  **Сдача смены:**
    *   Выдать финальный статус-рапорт и встать на якорь.
