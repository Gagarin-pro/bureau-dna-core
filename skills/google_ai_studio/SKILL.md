## 🔑 2. ПОЛУЧЕНИЕ И УПРАВЛЕНИЕ API-КЛЮЧАМИ
Для получения новых или проверки существующих ключей доступа:
1.  Перейди на страницу консоли управления: [aistudio.google.com](https://aistudio.google.com/).
2.  Нажми на боковую кнопку **"Get API key"** (Получить API-ключ).
3.  Создай новый ключ для проекта (`Create API key`) или выбери существующий для связки с конкретным Google Cloud проектом.
4.  Скопируй токен и запиши его в локальный файл переменных среды `.env` на Mac:
    `GEMINI_API_KEY=AIzaSy...`

*   **Температура (креативность):**
    *   `0.0` — максимальная строгость сборки (используется для генерации JSON, кода и математики).
    *   `1.0` — творческий поиск решений и мозговой штурм с Архитектором.
*   **Системная директива (System Instructions):**
    В поле системных инструкций всегда копируется регламент `АКТИВАТОР_СИСТЕМЫ.txt` для принудительной инициации роли Ведущего ИИ-Архитектора.

## 📂 4. ШИРОКИЙ КОНТЕКСТ: ЗАГРУЗКА БАЗЫ ЗНАНИЙ (ANTI-AMNESIA)
При работе с большими проектами (например, «Монолит» или «Gagarin OS») Бригадир собирает все файлы репозитория в единую текстовую выжимку (Snapshot) и импортирует ее в AI Studio:
1.  Запусти скрипт сборщика базы знаний:
    `python3 /Users/tur/Library/CloudStorage/GoogleDrive-n3804590@gmail.com/Мой диск/iT технологии/AI_Studio/Автошкола ИИ/«LEGO-ARCHITECT PRO»/01_ДНК_И_РЕГЛАМЕНТЫ/scripts/git_archivist.py`
2.  Скрипт создаст единый текстовый файл `.txt` со всем содержимым кодовой базы.
3.  Загрузи этот файл в левую панель Google AI Studio в качестве системного контекста (System Prompt / Files). Теперь модель видит 100% твоего кода без амнезии.
