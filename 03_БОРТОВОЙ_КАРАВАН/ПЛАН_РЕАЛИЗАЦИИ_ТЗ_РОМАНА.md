# 📋 ПЛАН РЕАЛИЗАЦИИ: ИТОГОВОЕ ТЗ РОМАНА (MONOLITH MINI APP)
> **Статус:** 🟢 УТВЕРЖДЕН К ИСПОЛНЕНИЮ | **Движок ИИ:** Gemini 3.6 Pro + Google Tools Ecosystem (Jules, AI Studio, Local Subagents)

---

## 🎯 1. ОБЗОР ЦЕЛЕЙ И КЛЮЧЕВЫЕ РЕШЕНИЯ ЮРИЯ
* **Принятое решение по TRC-20 (Трон):** Секция 5 (авто-прием USDT TRC-20) временно отложена для отдельного детального проектирования.
* **Принятое решение по Золотому Треугольнику:** Режим скрытия кнопки «Докупить до Треугольника» жестко привязан к математическому условию `left_node_id IS NOT NULL OR right_node_id IS NOT NULL` у верхнего кабинета. Как только в первой линии появляется 1-й партнер/перелив — кнопка докупки пропадает.
* **Новая фича по просьбе Юрия:** Внедрение кастомных пользовательских никнеймов (произвольное имя кабинета, настраиваемое пользователем) в СУБД, Fastify API, Mini App UI и Веб-админку.

---

## 🛠️ 2. РАСПРЕДЕЛЕНИЕ СУБАГЕНТОВ, ИНСТРУМЕНТОВ GOOGLE И СЕССИОННАЯ КАРТА

Чтобы исключить переполнение контекста (желтая зона) и дрейф внимания, реализация распределена по 2 сессиям и 3 типам ИИ-агентов:

| Фаза / Задача | Ответственный исполнитель | Инструмент / Мотор | Локация исполнения |
| :--- | :--- | :--- | :--- |
| **Фаза 1: СУБД & Fastify API** (Кастомный никнейм, fix `start_param`) | **Ведущий ИИ-Архитектор** | Gemini 3.6 Pro (Локально) | **Сессия 1 (Текущий чат)** |
| **Фаза 2: Telegram Mini App UI** (5 пакетов, уровни 1-15, никнейм) | **Субагент `Self` / ИИ-Слесарь** | Antigravity SDK + Subagent Delegator | **Сессия 2 (Новый чат)** |
| **Фаза 3: Веб-Админка (`admin.html`)** (Visual Tree, SVG Mobile Fix, Реестр) | 🤖 **Google Jules** (Облачный агент) | Chrome CDP / Jules Web API | **Облачный станок (Параллельно)** |
| **Фаза 4: TDD & GCP VM Deploy** (Автотесты + rsync + docker rebuild) | **Субагент `Self`** | Fastify + Postgres MCP | **Сессия 2 (Новый чат)** |
