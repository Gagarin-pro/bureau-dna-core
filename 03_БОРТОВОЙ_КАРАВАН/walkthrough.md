# 🏁 Walkthrough: Реализация Темы 3 («Простой вентиль»)

В рамках текущего рабочего такта смены успешно смонтированы и запущены в эксплуатацию изменения по Теме 3.

---

## 🛠️ Выполненные изменения

1.  **Авторегистрация при запросе профиля:**
    *   В эндпоинт `GET /api/profile/:telegramId` интегрирован блок автоматического создания карточки пользователя.
    *   Если пользователь заходит в Mini App впервые через `MenuButton`, бэкенд не возвращает 404, а автоматически заводит его в СУБД с куратором `ID 1` (системный корень) и сразу отдает корректный профиль (статус 200). Это исключило зависание загрузчика.

2.  **Валидация Telegram Web App Data:**
    *   Внедрены вспомогательные методы `parseTelegramInitData` и `validateTelegramInitData` для HMAC-SHA256 подписи входящих данных.

3.  **Привязка/смена кошелька:**
    *   Создан новый шлюз `POST /api/profile/wallet`, позволяющий пользователю в любой момент привязать или сменить кошелек USDT-TRC20 из личного кабинета.

4.  **Авто-отправка ссылок на обучение:**
    *   Написан асинхронный отправитель `sendStudyLink(telegramId, level)`.
    *   При покупке уровня (через `/api/profile/buy-level` или `/api/pay`) бэкенд автоматически обращается к Telegram Bot API и отсылает пользователю сообщение с пригласительной ссылкой на закрытый обучающий канал, привязанный к активированному уровню (поддерживается до 11 уровней обучения).
