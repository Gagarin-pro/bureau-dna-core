## 📡 ФИЗИЧЕСКИЙ ШЛЮЗ И ЗАПУСК CHROME (ДЛЯ АВТОПИЛОТА)
Для автоматического управления поиском через WebSocket (порт 9222) на macOS действуют строгие физические правила запуска:
1.  **Запрет дефолтной папки:** Браузер Chrome блокирует работу удаленного порта отладки на стандартном пользовательском профиле во избежание кражи паролей сайтами.
2.  **Формула запуска:** Браузер обязан запускаться с выделенным каталогом данных:
    `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --remote-debugging-port=9222 --user-data-dir="/Users/tur/Desktop/notebook_lm_school/chrome_profile"`
3.  **Сброс зависших сессий:** Перед повторным стартом все старые процессы Chrome должны быть завершены с помощью `killall "Google Chrome"`, иначе новый процесс молча делегирует управление старому без открытия порта 9222.
