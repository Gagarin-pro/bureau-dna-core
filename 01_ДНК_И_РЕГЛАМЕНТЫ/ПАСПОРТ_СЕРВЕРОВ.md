```
        │                  MacBook Air (Стас / Юрий)             │
        └──────────────┬──────────────────────────┬──────────────┘

           [Веб-пульт (порт 2080)]        [Локальный мост]
                       │                          │
                       v                          v
      ┌──────────────────────────────┐  ┌──────────────────────────────┐
      │        GCP СЕРВЕР            │  │         VPS TIMEWEB          │
      │        35.229.90.22          │  │        216.57.106.146        │
      ├──────────────────────────────┤  ├──────────────────────────────┤
      │ • Fastify API (4 vCPU, 16G)  │  │ • amnezia-xray (1 vCPU, 1G)  │
      │ • n8n Диспетчер              │  │ • Flask ( Мозг Гагарина )    │

      └──────────────────────────────┘  └──────────────────────────────┘
```
*   **Локальный ПК ⇄ GCP:** Telegram Web App отправляет запросы на `sslip.io` ➔ Caddy проксирует в Fastify.
*   **GCP ⇄ VPS:** В будущих фазах бэкенд Монолита посылает SSH-команды на VPS для вызова `add_xray_user()` через Paramiko.
*   **Локальный ПК ⇄ VPS:** Скрипт `gagarin_bridge.py` на ПК ученика раз в 3 секунды опрашивает Flask-сервер (`/api/next`) на VPS по защищенному ключу `X-Bridge-Key`.
