# 🗂️ КАРТОТЕКА СУБАГЕНТОВ БЮРО
> **Статус конвейера:** 🟢 Активен | **Дата обновления:** 19 июля 2026

Этот документ содержит реестр всех специализированных ИИ-станков и роботов-помощников Автономного Бюро. Бригадир (Antigravity) обязан использовать эту базу для распределения задач и привлекать нужных специалистов для параллельной работы.

---

## 👥 1. ФОНОВЫЕ СУБАГЕНТЫ (ВЕРСТАКИ ИИ)
Вызываются асинхронно через инструмент `invoke_subagent` для параллельной обработки тяжелых задач без засорения основного контекста КВС.

### 🔍 Агент «Research» (Подмастерье-Исследователь)
*   **Специализация:** Сбор информации, чтение внешних веб-страниц, анализ документации, поиск библиотек.
*   **Модель:** `inherit` (Gemini Flash/Pro).
*   **Сборочный наряд (Когда вызывать):** Когда требуется проанализировать присланные ссылки, провести разведку рынка, вытащить данные с сайтов или сравнить технические решения.

### 🛠️ Агент «Self» (Подмастерье-Исполнитель)
*   **Специализация:** Написание кода, сборка модулей, рефакторинг, запуск тестовых стендов.
*   **Модель:** `inherit` (Gemini Pro/Flash).
*   **Сборочный наряд (Когда вызывать):** Когда нужно написать объемный код, провести рефакторинг существующего файла или запустить длительный процесс отладки, не останавливая диалог с КВС.

### 🤖 Агент «PlanOrchestrator» (ИИ-Оркестратор планов)
*   **Специализация:** Координация сложных многоэтапных задач по Obsidian-плану (`task.md`). Вызов исполнительных (`Self`) и контролирующих (`Research`) субагентов с лимитом на 3 попытки авторемонта.
*   **Модель:** `pro` (Gemini Pro/Claude Sonnet) для оркестрации; `inherit` для подчиненных.
*   **Сборочный наряд (Когда вызывать):** При запуске комплексных сборок с автоматической проверкой синтаксиса и тестированием живьем.

## ⚙️ 2. ЛОКАЛЬНЫЕ ИСПОЛНИТЕЛЬНЫЕ РОБОТЫ (СКРИПТЫ MAC)
Запускаются локально на Macbook КВС для выполнения конкретных сервисных задач.

### 🗂️ Robot «mac_file_scout» (ИИ-Секретарь Mac)
*   **Путь:** `/04_ДИСТРИБУТИВ/mac_file_scout.py`
*   **Назначение:** Сканирование `Downloads`, `Desktop`, `Documents` КВС на предмет новых схем, инструкций или скриншотов.
*   **Запуск:** Автоматически при старте смены.

### 📝 Robot «shift_agent» (ИИ-Писец смены)
*   **Путь:** `/04_ДИСТРИБУТИВ/shift_agent.py`
*   **Назначение:** Архивация смены, сборка «Сменного Прицепа Памяти», очистка логов чата и подготовка когнитивного отсека к следующей планерке.
*   **Запуск:** Вызывается при закрытии смены (`/end_shift`).

### 📐 Robot «skills_auditor» (Ревизор умений)
*   **Путь:** `/01_ДНК_И_РЕГЛАМЕНТЫ/scripts/skills_auditor.py`
*   **Назначение:** Инвентаризация активных когнитивных плагинов и умений ИИ.
*   **Запуск:** Команда `/audit`.

### 🖨️ Robot «print_assistant» (ИИ-Печатник и верстальщик)
*   **Путь:** `/04_ДИСТРИБУТИВ/print_assistant.py`
*   **Назначение:** Верстка Markdown судебных документов по гибридному стандарту (без красной строки, сжатые поля, шапка справа, заголовок по центру, многоступенчатый подгон шрифта от 13pt до 9.5pt для укладывания в 1 лист). Генерация PDF через headless Chrome, создание снимка-превью через qlmanage для Electron и отправка на физический принтер через lp.
*   **Запуск:** Экспресс-команда `/print <путь_к_md_файлу>` или прямой вызов `python3`.

## 🔒 3. ПРАВИЛА ПРОАКТИВНОГО ПРИЗЫВА (ДНК ФОКУСА)
*   **Автономный выбор:** Если задача превышает 100 строк кода или требует анализа более 3 веб-ссылок, Бригадир обязан не выполнять ее в основном окне, а проактивно предложить КВС: *«ЦЕЛЬ: Я хочу делегировать эту задачу субагенту [Имя Агента]. Выдаю наряд на запуск...»*
*   **Постоянный учет:** Информация о выданных нарядах и статусе работы субагентов выводится на приборную панель в реальном времени.
